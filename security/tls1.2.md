# TLS 1.2 技术原理详解

## 一、TLS 1.2 的本质

TLS 1.2 的核心是：在不可信的网络中，让客户端与服务端建立一条经过身份验证、加密和完整性保护的通信通道。



它主要解决三个问题：

| 安全目标 | 解决的问题                               | 核心技术                      |
| -------- | ---------------------------------------- | ----------------------------- |
| 身份认证 | 如何确认连接的是真实服务器，而不是攻击者 | 数字证书、CA 信任链、数字签名 |
| 密钥协商 | 如何通过不安全的网络建立双方共享的密钥   | ECDHE 密钥交换                |
| 安全传输 | 如何防止通信被窃听、篡改                 | AES-GCM 等对称认证加密算法    |



TLS 使用非对称密码技术完成身份认证和密钥交换，使用高性能对称加密算法保护实际业务数据。



## 二、TLS 1.2 使用哪些密码学算法？

以一种典型的 TLS 1.2 密码套件为例：

```
TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256
```

| 组成部分 | 用途                                    |
| -------- | --------------------------------------- |
| ECDHE    | 交换临时公钥，计算共享密钥              |
| RSA      | 通过数字签名认证服务器身份              |
| AES-128  | 使用 128 位对称密钥加密数据             |
| GCM      | 提供加密和完整性验证                    |
| SHA256   | 用于握手中的 PRF 密钥派生及相关摘要计算 |
