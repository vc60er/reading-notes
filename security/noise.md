## 一、Noise 解决什么问题？



在安全通信，需要解决四个问题：

| 问题     | Noise 的解决方式                               |
| -------- | ---------------------------------------------- |
| 数据保密 | 使用对称加密保护数据                           |
| 身份认证 | 使用长期公私钥验证通信方身份                   |
| 密钥协商 | DH 算法协商共享密钥，不直接传输密钥            |
| 前向保密 | 使用临时密钥，降低长期私钥泄露对历史通信的影响 |

Noise 将这些机制组织成标准化的握手协议，避免开发者自行设计复杂且容易出错的密码学交互。
